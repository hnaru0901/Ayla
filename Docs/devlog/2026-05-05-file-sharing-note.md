# 2026-05-05 파일 공유 방식 검토

## 오늘 정리한 것

- Git을 활용한 파일 공유 방식을 검토했습니다.
- Unity 에셋까지 포함해서 공유하려면 Git LFS 사용 방법을 배워야 합니다.
- Git LFS는 용량 제한 이슈가 있어 현재 방식으로는 부담이 있습니다.

## 판단한 것

- 개발 채널에 올라가는 저장소는 에셋을 포함하지 않고 코드 중심으로 관리합니다.
- 에셋까지 포함한 전체 프로젝트 공유가 필요하면 압축파일로 전달하는 방식이 현실적입니다.

## 남은 것

- Git LFS를 실제로 도입할지는 프로젝트 에셋 규모가 커진 뒤 다시 판단합니다.
- 당장은 코드와 문서 중심으로 GitHub를 사용합니다.

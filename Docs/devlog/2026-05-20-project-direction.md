# 2026-05-20 프로젝트 방향 점검

## 오늘 한 것

- `#21 대량 아이템 에셋 제작 전 게임 방향 최종 점검`을 기준으로 Ayla의 장르 방향을 다시 확인했다.
- 현재 방향을 작은 3D 마녀 공방 운영 게임으로 확정했다.
- 기존 고정 조건을 정리했다.
  - 주연 캐릭터 4인방 일러스트가 이미 있음
  - 에일라가 주인공
  - 판타지/일본 아니메풍
  - Chibi 3D
  - Unity3D
  - 마녀/마법 테마
- 다른 장르 후보를 검토했지만, 첫 Unity3D 게임과 취미 개발 범위에서는 공방 운영이 가장 현실적이라고 판단했다.
- 집/가게 주변에서 확장 가능한 콘텐츠를 정리했다.
  - 장사 운영
  - 공방 업그레이드
  - 레시피 공부
  - 집 꾸미기
  - 밭 개간과 재배
  - 보관/정리
  - 우편함/게시판
  - 방문자 응대
- 공방 꾸미기와 장사 운영을 연결할 수 있는 공방 스탯 후보를 정리했다.
  - 아늑함
  - 효율
  - 신비로움
  - 집중력
- 장소 확장 후보를 정리했다.
  - 에일라의 집/가게
  - 집 주변 숲 산책로
  - 근처 바닷가 마을 또는 모험가 캠프
  - 던전
- 전투/탐험은 흥미롭지만 후속 검토로 미뤘다.
- 포션 던지기는 첫 playable 필수 요소가 아니라 후속 콘셉트 후보로 기록했다.
- 대량 에셋 제작을 위한 1차/2차 카테고리 초안을 만들었다.
- 친구에게 쉽게 공유할 수 있도록 프로젝트 방향 시각화 HTML과 PNG를 만들었다.

## 확인한 것

- Ayla의 기준 장르는 기존처럼 작은 3D 마녀 공방 운영 게임으로 유지한다.
- 새 장르를 찾는 것보다, 대량 에셋 제작 전에 어떤 아이템과 콘텐츠 축이 필요한지 정리하는 것이 더 중요했다.
- 일반 인벤토리와 공방 자산은 분리하는 쪽이 자연스럽다.
- 도구와 장비는 분리한다.
  - 도구는 행동이나 작업을 가능하게 하는 물건
  - 장비는 착용하거나 능력에 영향을 주는 물건
- 전투/탐험은 지금 별도 1차 카테고리로 확정하지 않는다.
- 에셋 분류는 게임 내 분류와 같은 언어를 쓰되, 실제 대량 제작 전에 애매한 경계는 다시 다듬는다.

## 남은 것

- 대량 에셋 제작 전에 2차 카테고리별 실제 예시 목록을 더 채워야 한다.
- 재료의 `열매/씨앗`과 재배의 `씨앗`처럼 겹치는 분류를 나중에 정리해야 한다.
- 수납 가구와 보관 설비의 경계를 다시 봐야 한다.
- 전투/탐험을 실제로 넣을지, 넣는다면 어떤 방식일지 후속으로 판단해야 한다.

# 2026-05-19 포션 제작 도구 흐름 확장

## 오늘 한 것

- 선반에서 `Q/E`로 하얀 원재료와 빨간 원재료를 선택할 수 있게 했습니다.
- 하얀/빨간 재료가 손질대 -> 솥 -> 병입대까지 각각 다른 제작 라인으로 이어지게 했습니다.
- 하얀 계열은 3초, 빨간 계열은 5초로 제작 시간이 다르게 적용되게 했습니다.
- 솥은 재료를 넣으면 자동으로 진행되게 해서, 손질대/병입대와 사용 방식 차이를 만들었습니다.
- 플레이어가 들고 있는 아이템과 도구 위에 올라간 재료/결과물이 아이콘으로 보이게 했습니다.
- 기존 진행도 텍스트는 유지하고, 색상 구체 표시는 제거해도 동작하게 정리했습니다.
- 손질대 2개, 솥 2개, 병입대 1개 구성에서 병목과 동선을 확인할 수 있게 했습니다.

## 확인한 것

- 하얀 원재료와 빨간 원재료를 선반에서 고르고 들 수 있습니다.
- 하얀/빨간 제작 라인이 각각 다른 결과물로 이어집니다.
- 빨간 계열이 하얀 계열보다 오래 걸립니다.
- 솥은 플레이어가 붙어 있지 않아도 자동으로 진행됩니다.
- 도구 위 아이콘 덕분에 재료가 올라가고 결과물로 바뀌는 느낌이 이전보다 잘 보입니다.

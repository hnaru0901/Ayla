# 2026-05-11 기본 들기와 버리기 구현

- 플레이어가 재료를 들고 다닐 수 있는 기본 상태를 구현했습니다.
- 한 번에 하나의 아이템만 들 수 있는 규칙을 확인했습니다.
- 들고 있는 재료를 쓰레기통에 버릴 수 있게 했습니다.

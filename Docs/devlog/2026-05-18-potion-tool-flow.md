# 2026-05-18 포션 제작 도구 흐름 준비

## 오늘 한 것

- 작업실 바닥을 넓혀서 도구를 더 배치하고 동선을 확인할 수 있게 했습니다.
- 제작 도구를 추가 배치해서 병목과 이동 거리감을 보기 시작했습니다.
- 선반에서 재료를 바로 받는 방식 대신, 재료를 선택하는 흐름을 만들기 시작했습니다.
- 하얀 재료와 빨간 재료를 나눠서 이후 제작 시간 차이를 줄 수 있는 방향으로 정리했습니다.

## 확인한 것

- 도구가 늘어나면 단순 제작보다 동선 판단이 조금 더 생깁니다.
- 병입대가 적으면 마지막 단계에서 병목이 생길 가능성이 있습니다.
- 재료 선택이 들어가면 이후 주문/판매 단계에서 어떤 포션을 만들지 선택하는 기반이 됩니다.

## 남은 것

- 선택한 재료가 실제로 플레이어 손에 들어오게 해야 합니다.
- 하얀 재료와 빨간 재료의 제작 시간을 다르게 적용해야 합니다.
- 솥처럼 자동으로 돌아가는 도구를 만들어 도구별 사용 방식 차이를 줘야 합니다.

## 다음 작업

- 선반에서 선택한 재료를 플레이어가 들게 합니다.
- 하얀 계열은 3초, 빨간 계열은 5초로 제작 시간을 다르게 합니다.
- 솥은 재료를 넣으면 자동으로 진행되게 구현합니다.

Ayla Project Direction

Scope Guard

첫 playable은 작게 유지한다. 큰 인벤토리, 꾸미기, 재배, 전투, 공방 스탯 아키텍처를 먼저 만들지 않는다.

다만 일반 인벤토리와 공방 자산, 도구와 장비, 확정 시스템과 후속 후보가 나중에 분리될 수 있도록 데이터 구조는 막히지 않게 둔다.
